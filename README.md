# Thư mục bài tập thiết kế đồ họa của Zuzong

- `Web_Cuoi_Ky/`: mã nguồn, ảnh, video, thư viện, tài liệu và bản build của website ZUZONG CAR cuối kỳ. Chỉnh sửa web trong thư mục này.
- `output/ZUZONG_CAR_Giua_Ky/`: các sản phẩm bài giữa kỳ.
- `output/`: các file Word, PowerPoint, PSD, ZIP, ảnh gốc và kết quả đã xuất trước khi tách web.
- `tmp/`: các file làm việc từ những lần thực hiện trước.

## Chạy website cuối kỳ

```powershell
cd E:\du_dan_cuoi_ky_tkdh\Web_Cuoi_Ky
node server.cjs
```

Mở http://localhost:4173. Xem hướng dẫn chi tiết trong `Web_Cuoi_Ky/README.md`.

Kết quả build, kiểm tra và xuất file web mới nằm trong `Web_Cuoi_Ky/dist/`, `Web_Cuoi_Ky/output/` và `Web_Cuoi_Ky/tmp/` để tách khỏi các bài khác.
